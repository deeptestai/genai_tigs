# Using the Gradio UI

1. Select a **model** (VAE / GAN / Diffusion).
2. Set **perturbation** parameters.
3. Click **Run** → view original vs. perturbed images + predictions.
4. Download outputs from the gallery or `/app/output` (or your mounted folder).
